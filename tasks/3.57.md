# Задание 3.57

Какая из реляционно-алгебраических операций используется процедурой декомпозиции
отношений в процессе их нормализации? Приведите примеры применения этой операции
в процессе нормализации отношений.

---

В процессе нормализации отношений основной реляционно-алгебраической операцией
является **проекция (PROJECT, π)**.

Суть нормализации заключается в том, что исходное отношение разбивается на
несколько более простых отношений. Каждое из новых отношений получается выбором
части атрибутов исходного отношения, то есть операцией проекции.

## Пояснение

Пусть имеется отношение:

```sql
СТУДЕНТЫ(
    StudentID,
    StudentName,
    GroupName,
    CuratorName
)
```

Если существуют функциональные зависимости:

```sql
StudentID → StudentName, GroupName
GroupName → CuratorName
```

то отношение не находится в 3НФ, поскольку имеется транзитивная зависимость:

```sql
StudentID → GroupName → CuratorName
```

Для устранения этой зависимости выполняется декомпозиция:

```sql
R1 = π(StudentID, StudentName, GroupName)(СТУДЕНТЫ)

R2 = π(GroupName, CuratorName)(СТУДЕНТЫ)
```

В результате получаются два отношения:

```sql
СТУДЕНТЫ(StudentID, StudentName, GroupName)

ГРУППЫ(GroupName, CuratorName)
```

---

## Пример приведения к 2НФ

Исходное отношение:

```sql
УСПЕВАЕМОСТЬ(
    StudentID,
    SubjectID,
    StudentName,
    Mark
)
```

Ключ:

```sql
(StudentID, SubjectID)
```

Функциональная зависимость:

```sql
StudentID → StudentName
```

Здесь атрибут `StudentName` зависит только от части составного ключа, поэтому
выполняется декомпозиция:

```sql
R1 = π(StudentID, StudentName)(УСПЕВАЕМОСТЬ)

R2 = π(StudentID, SubjectID, Mark)(УСПЕВАЕМОСТЬ)
```

Получаем:

```sql
СТУДЕНТЫ(StudentID, StudentName)

УСПЕВАЕМОСТЬ(StudentID, SubjectID, Mark)
```

---

## Итог

Хотя декомпозиция выполняется с помощью **проекций**, ее корректность обычно
проверяется через возможность восстановления исходного отношения операцией
**соединения (JOIN)** без потерь данных. Поэтому нормализация фактически
опирается на пару операций:

1. **Проекция** — для разбиения отношения.
2. **Соединение** — для проверки декомпозиции без потерь.

**Процедура декомпозиции отношений при нормализации использует операцию проекции
(π), а правильность декомпозиции контролируется с помощью операции соединения
(JOIN).**
