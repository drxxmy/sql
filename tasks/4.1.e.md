# Задание 4.1.e

Составьте SQL-запрос:

> выборка сотрудников, стаж работы которых превышает n лет (n задается
> параметром, значение которого запрашивается у пользователя)

---

## Ответ

```sql
DECLARE @n INT;

SELECT *
FROM Сотрудники
WHERE ДатаНайма < DATEADD(YEAR, -@n, GETDATE());
```

Где:

- `Сотрудники` - таблица сотрудников;
- `ДатаНайма` - дата приема на работу;
- `@n` - параметр (минимальный стаж в годах).
