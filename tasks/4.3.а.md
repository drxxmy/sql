# Задание 4.3.а

Составьте SQL-запрос:

> для получения объединенного списка контрагентов (клиентов и поставщиков).

---

## Ответ

```sql
SELECT
    Код_Клиента AS Код,
    Клиент AS Наименование,
    Телефон,
    КодГорода,
    'Клиент' AS ТипКонтрагента
FROM Клиенты

UNION

SELECT
    Код_Поставщика AS Код,
    Поставщик AS Наименование,
    Телефон,
    КодГорода,
    'Поставщик' AS ТипКонтрагента
FROM Поставщики;
```
