# Задание 4.4.т

Составьте SQL-запрос:

> для обновления цен реализации всех заказанных товаров категории _Приправы_ в
> соответствии с торговой наценкой, заданной для этой категории товаров

---

## Ответ

```sql
UPDATE z
SET z.БазоваяЦенаРеализации =
    z.БазоваяЦенаРеализации * (1 + c.ТорговаяНаценка)
FROM Заказано z
INNER JOIN Склад s
    ON z.Код_Товара = s.КодТовара
INNER JOIN Категории c
    ON s.Код_Категории = c.Код_Категории
WHERE c.Категория = N'Приправы';
```
