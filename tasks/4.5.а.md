# Задание 4.5.а

Оцените результаты следующих SQL-запросов:

```sql
SELECT COUNT(*) FROM Города;
SELECT COUNT(КодСтраны) FROM Города;
SELECT COUNT(*), КодСтраны FROM Города;
SELECT COUNT(*), КодСтраны FROM Города
    GROUP BY КодСтраны;
SELECT COUNT(*), КодСтраны FROM Города
    GROUP BY КодСтраны HAVING Count(*)>10;
SELECT COUNT(*), Города.КодСтраны, Страны.КодРегиона
    FROM Регионы INNER JOIN (Страны INNER JOIN Города
        ON Страны.КодСтраны = Города.КодСтраны)
        ON Регионы.Код_Региона = Страны.КодРегиона
    GROUP BY Страны.КодРегиона, Города.КодСтраны;
SELECT COUNT(*), Города.КодСтраны, Страны.КодРегиона
    FROM Регионы INNER JOIN (Страны INNER JOIN Города
        ON Страны.КодСтраны = Города.КодСтраны)
        ON Регионы.КодРегиона = Страны.КодРегиона
    GROUP BY Города.КодСтраны, Страны.КодРегиона;
SELECT AVG(Товары.ЦенаПоставщика), Категории.Категория
    FROM Категории INNER JOIN Склад ON
        Категории.Код_Категории = Склад.КодКатегории
    GROUP BY Категории.Категория
    HAVING AVG(Склад.Количество)>30;
SELECT Город, COUNT(*) AS [Количество клиентов]
    FROM Города INNER JOIN Клиенты ON
        Города.Код_Города = Клиенты.КодГорода
    GROUP BY Город;
SELECT Город FROM Города WHERE
    (SELECT COUNT(*) FROM Клиенты
    WHERE Города.Код_Города = Клиенты.КодГорода)>2;
```

---

## 1. Простой подсчёт строк

```sql
SELECT COUNT(*) FROM Города;
```

**Результат:** `105`

Подсчитывает все строки таблицы, включая `NULL`.

---

## 2. Подсчёт по столбцу

```sql
SELECT COUNT(КодСтраны) FROM Города;
```

**Результат:** `104`

`COUNT(столбец)` игнорирует `NULL`. Здесь один город без указанной страны.

---

## 3. Агрегат без группировки

```sql
SELECT COUNT(*), КодСтраны FROM Города;
```

**Результат:** `(105, 221)` (или любое другое значение КодСтраны)

Без `GROUP BY` агрегат возвращает одну строку, а неагрегатный столбец берётся
произвольно. Запрос некорректен.

---

## 4. Группировка

```sql
SELECT COUNT(*), КодСтраны 
FROM Города 
GROUP BY КодСтраны;
```

**Результат:** Список пар `(количество, КодСтраны)`, например: `(1, NULL)`,
`(2, 208)`, `(15, 230)` и т.д.

Правильный способ получить количество городов по каждой стране.

---

## 5. Группировка + HAVING

```sql
SELECT COUNT(*), КодСтраны 
FROM Города 
GROUP BY КодСтраны 
HAVING COUNT(*) > 10;
```

**Результат:**

- `(12, 216)`
- `(15, 230)`
- `(11, 233)`

`HAVING` фильтрует группы после агрегации. Показывает только страны с более чем
10 городами.

---

## 6–7. JOIN + GROUP BY (два варианта)

```sql
SELECT COUNT(*), Города.КодСтраны, Страны.КодРегиона
FROM Регионы INNER JOIN (Страны INNER JOIN Города ON Страны.КодСтраны = Города.КодСтраны)
    ON Регионы.Код_Региона = Страны.КодРегиона
GROUP BY Страны.КодРегиона, Города.КодСтраны;
```

Проблема в оригиналах: неверное имя столбца (`Страны.КодСтраны` ->
`Страны.Код_Страны`).

Исправленный вариант (оба запроса дают одинаковый результат):

```sql
SELECT COUNT(*) AS КоличествоГородов, 
       Города.КодСтраны, 
       Страны.КодРегиона
FROM Регионы 
INNER JOIN Страны ON Регионы.Код_Региона = Страны.КодРегиона
INNER JOIN Города ON Страны.Код_Страны = Города.КодСтраны
GROUP BY Города.КодСтраны, Страны.КодРегиона;
```

Показывает количество городов по комбинации страна + регион. Порядок `GROUP BY`
влияет только на сортировку вывода.

---

## 8. AVG + JOIN + HAVING

Оригинал: Ошибка - нет таблицы `Товары` и столбца `ЦенаПоставщика`. Исправленный
вариант (использовал `Склад.ОптоваяЦена` и правильный `Код_Категории`):

```sql
SELECT AVG(Склад.ОптоваяЦена) AS СредняяЦена, 
       Категории.Категория
FROM Категории 
INNER JOIN Склад ON Категории.Код_Категории = Склад.КодКатегории
GROUP BY Категории.Категория
HAVING AVG(Склад.Количество) > 30;
```

**Результат** (примеры):

- Кондитерские изделия -> ~1132.2
- Молочные продукты -> ~1293.85
- Мясо/птица -> ~2112 и т.д.

`HAVING` применяется к агрегатной функции после группировки.

---

## 9. Количество клиентов по городам

```sql
SELECT Город, COUNT(*) AS [Количество клиентов]
FROM Города 
INNER JOIN Клиенты ON Города.Код_Города = Клиенты.КодГорода
GROUP BY Город;
```

**Результат:** Лондон - 6, Мехико - 5, Сан-Паулу - 4 и т.д.

---

## 10. Коррелированный подзапрос

```sql
SELECT Город 
FROM Города 
WHERE (SELECT COUNT(*) 
       FROM Клиенты 
       WHERE Города.Код_Города = Клиенты.КодГорода) > 2;
```

**Результат:** Буэнос-Айрес, Лондон, Мадрид, Мехико, Рио-де-Жанейро, Сан-Паулу.

Эффективный способ найти города с более чем 2 клиентами. Можно переписать через
`JOIN` + `HAVING` для лучшей производительности.
