# Задание 4.5.с

Составьте SQL-запрос:

> для определения перечня заказов, стоимость которых превышает среднюю.

## Ответ

```sql
SELECT 
    z.Код_Заказа,
    ROUND(SUM(zk.Количество * zk.БазоваяЦенаРеализации * (1 - zk.Скидка)), 2) AS СтоимостьЗаказа
FROM Заказы z
JOIN Заказано zk ON z.Код_Заказа = zk.Код_Заказа
GROUP BY z.Код_Заказа
HAVING СтоимостьЗаказа > (
    SELECT AVG(СтоимостьЗаказа)
    FROM (
        SELECT SUM(zk2.Количество * zk2.БазоваяЦенаРеализации * (1 - zk2.Скидка)) AS СтоимостьЗаказа
        FROM Заказы z2
        JOIN Заказано zk2 ON z2.Код_Заказа = zk2.Код_Заказа
        GROUP BY z2.Код_Заказа
    ) AS avg_orders
)
ORDER BY СтоимостьЗаказа DESC;
```

### Пояснения

- Стоимость заказа = `Количество × БазоваяЦенаРеализации × (1 - Скидка)`
  (суммируется по товарам в заказе).
- Запрос использует `GROUP BY` + `HAVING` для фильтрации по средней стоимости.
- Подзапрос вычисляет среднюю стоимость всех заказов.
- Добавлен `ROUND` для удобства и сортировка по убыванию.
