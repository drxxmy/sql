# Задание 4.6.в

Составьте перекрестный SQL-запрос, позволяющий:

> представить информацию о суммах выручки, полученных от реализации товаров, в
> координатах: `ПОСТАВЩИК – СОТРУДНИК`

## Ответ

```sql
SELECT 
    Поставщик,
    [Акбаев], [Бабкина], [Белова], [Воронова], 
    [Кралев], [Кротов], [Крылова], [Новиков], [Ясенева],
    Итого
FROM (
    SELECT 
        p.Поставщик,
        e.Сотрудник,
        z.БазоваяЦенаРеализации * z.Количество * (1 - z.Скидка) AS Выручка
    FROM Заказано z
    JOIN Заказы ord ON z.Код_Заказа = ord.Код_Заказа
    JOIN Сотрудники e ON ord.Код_Сотрудника = e.Код_Сотрудника
    JOIN Склад s ON z.Код_Товара = s.КодТовара
    JOIN Поставщики p ON s.Код_Поставщика = p.Код_Поставщика
) AS Source
PIVOT (
    SUM(Выручка)
    FOR Сотрудник IN (
        [Акбаев], [Бабкина], [Белова], [Воронова], 
        [Кралев], [Кротов], [Крылова], [Новиков], [Ясенева]
    )
) AS PivotTable
CROSS JOIN (
    SELECT SUM(z.БазоваяЦенаРеализации * z.Количество * (1 - z.Скидка)) AS Итого
    FROM Заказано z
    JOIN Заказы ord ON z.Код_Заказа = ord.Код_Заказа
    JOIN Сотрудники e ON ord.Код_Сотрудника = e.Код_Сотрудника
    JOIN Склад s ON z.Код_Товара = s.КодТовара
    JOIN Поставщики p ON s.Код_Поставщика = p.Код_Поставщика
) AS Total
ORDER BY Поставщик;
```

## Пояснения

### Общая структура

Запрос состоит из трёх основных частей:

1. Внутренний подзапрос - готовит _плоские_ данные.
2. Блок **PIVOT** - выполняет поворот таблицы (превращает строки в столбцы).
3. **CROSS JOIN** - добавляет общую итоговую сумму по поставщику.

### Подробный разбор

**Внутренний подзапрос (Source)** Собирает исходные данные для поворота. Он
соединяет нужные таблицы:

- `Заказано` + `Заказы` + `Сотрудники` - для получения сотрудника и заказа;
- `Склад` + `Поставщики` - для получения поставщика товара. Для каждой позиции
  рассчитывается выручка по формуле:
  `БазоваяЦенаРеализации × Количество × (1 - Скидка)`.

**Блок PIVOT** - основной механизм перекрестного запроса в SQL Server.

- Агрегирует (суммирует) выручку.
- Значения поля `Сотрудник` превращает в отдельные столбцы.
- Каждый столбец содержит сумму выручки от конкретного сотрудника по данному
  поставщику. Квадратные скобки вокруг имён сотрудников обязательны из-за
  использования кириллицы.

**CROSS JOIN с итоговой суммой** - добавляет к каждой строке (поставщику) один
дополнительный столбец `Итого` - общую выручку по этому поставщику независимо от
сотрудников. Позволяет показать итог без повторного расчёта.

### Что возвращает запрос

- **Строки** - поставщики.
- **Столбцы** - сотрудники (Акбаев, Бабкина, Белова и т.д.).
- **Значения в ячейках** - сумма выручки от реализации товаров данного
  поставщика конкретным сотрудником.
- **Последний столбец** - итоговая выручка по поставщику.
