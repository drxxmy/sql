# Задание 4.6.г

Составьте перекрестный SQL-запрос, позволяющий:

> представить информацию о суммах выручки, полученных от реализации товаров, в
> координатах: `КЛИЕНТ – ТОВАР`.

---

## Ответ

```sql
DECLARE @columns NVARCHAR(MAX) = '';
DECLARE @sql NVARCHAR(MAX);

-- Собираем имена товаров
SELECT @columns = STRING_AGG(QUOTENAME(Товар), ', ')
FROM (SELECT DISTINCT Товар FROM Склад) AS t;

-- Формируем текст динамического SQL-запроса
SET @sql = '
SELECT Клиент, ' + @columns + '
FROM (
    SELECT k.Клиент, s.Товар, 
           SUM(za.Количество * za.БазоваяЦенаРеализации * (1 - za.Скидка / 100.0)) AS Выручка
    FROM Заказы z
    JOIN Клиенты k ON z.Код_Клиента = k.Код_Клиента
    JOIN Заказано za ON z.Код_Заказа = za.Код_Заказа
    JOIN Склад s ON za.Код_Товара = s.КодТовара
    GROUP BY k.Клиент, s.Товар
) AS Source
PIVOT (
    SUM(Выручка) 
    FOR Товар IN (' + @columns + ')
) AS PivotTable
ORDER BY Клиент;';

-- Выполняем динамический запрос
EXEC sp_executesql @sql;
```

---

### Пояснения

1. Сбор названий столбцов (`@columns`)
   - `STRING_AGG(QUOTENAME(Товар), ', ')` - собирает все уникальные названия
     товаров из таблицы Склад в одну строку, разделённую запятыми.
   - `QUOTENAME()` автоматически оборачивает названия в квадратные скобки
     `[ ]` - обязательно, если в названии есть пробелы, апострофы или другие
     спецсимволы (например, `["Jack's New England Clam Chowder"]`).
   - Результат:
     `[Chang], [Chartreuse verte], ["Jack's New England Clam Chowder"], ...`
2. Построение текста SQL-запроса
   - Переменная `@sql` содержит весь запрос как строку.
   - Вставляем `@columns` в два места:
     - В список выбираемых полей после `Клиент`.
     - В секцию `FOR Товар IN (...)` оператора `PIVOT`.
3. Выполнение
   - `EXEC sp_executesql @sql` - выполняет сформированную строку как SQL-запрос.
   - Это позволяет обработать все товары автоматически, без ручного
     перечисления.
